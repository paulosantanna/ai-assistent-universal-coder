# Frame and copy

`FrameStage` builds one frame per ranked video. The phrase uses the sentiment palette in the creative module. The source is fitted inside the frame. It is not cropped into a new shot.

`CopyStage` writes one description and up to five tags per publish network. Tags are tied to that video.

`ReviewStage` and the stage gates record a verdict per piece: pass, revise, or fail. A blocking gate stops the run. Do not add a second caption or frame path.

On the desktop, the classified file can be downloaded when the video is selected. Publishing still composes the final file at post time.
