# wordpress-expert

Staff-level WordPress super-skill for the single `codenavi-agent`.

Key properties:

- evidence-first knowledge through `wordpress-knowledge` MCP;
- official WordPress docs are normative, Reddit is experiential evidence;
- governed AI-assisted project creation/modification through `AI_ASSISTED_DEVELOPMENT.md`;
- builds explicit non-secret project context and acceptance criteria before generated code;
- plan-before-mutation, incremental implementation and diff-first review instead of unconstrained AI rewrites;
- clean-code rules for PHP/WordPress, JavaScript/blocks and CSS/UI with maintainability as a definition-of-done requirement;
- Cursor/Codex/Copilot/editor output is acceleration only, never normative evidence;
- external cookie/cookie-jar file authentication is allowed and expected for wp-admin sessions;
- one-shot read-only Beta Mapping per site;
- later runs reuse the map and perform lightweight delta/preflight only;
- supports Gutenberg/block themes, classic/child themes, **all installed plugins**, layouts, content, REST, WP-CLI patterns and production operations;
- complete plugin universe: `skills/wordpress-expert/PLUGINS.md`; KingHost publish includes `wp-content/plugins` and `wp-content/mu-plugins`;
- supports third-party service links/APIs including 99, Mercado Livre, Mercado Pago, Keeta, TikTok, iFood and social networks;
- icon/favicon-first external UI with accessibility fallback;
- only real executed checks count as verification evidence;
- production writes require rollback and verification;
- WordPress core edits for feature work are prohibited.
