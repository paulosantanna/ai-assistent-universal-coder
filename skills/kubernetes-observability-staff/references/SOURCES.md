## Source Use Rules

- Use official documentation as baseline behavior, not as proof that the user's environment is configured correctly.
- Verify product/version-specific behavior against the actual environment when evidence is available.
- Mark any claim not backed by telemetry, exported evidence, command output, file reference or official source as `UNVERIFIED`.
