# Mantis Suite

AEOS installation wrapper for the Mantis defensive security review skills from `E:\GitHub\mantis`.

The original Mantis contracts are preserved under each skill's `references/ORIGINAL_SKILL.md`. The AEOS `SKILL.md` files provide governance, activation and evidence boundaries while delegating stage-specific behavior to those original contracts.

Use the `mantis` playbook to run the full orchestrated review sequence.
