# AI Production Autopilot

This AEOS playbook coordinates a complete project path from architecture to tested implementation, N8N automation, security review, documentation and release readiness.

It is intentionally strict. It does not approve architecture, code, tests, security or documentation below 10/10. A blocker remains a blocker even when partial work is useful.

## Core Skills

- `staff-iii-architecture-governor`
- `staff-tdd-code-builder`
- `documentation-11-layer-mapper`
- `security-audit`
- `dependency-analyzer`
- `test-generation`
- `diff-reviewer`
- `aeos-autonomous-learning-governor`

## Completion Standard

The playbook completes only when the project has architecture evidence, TDD evidence, stress-oriented tests, multi-source CVE review, N8N integration evidence when applicable, 11-layer documentation, production readiness review and independent Judge approval.
