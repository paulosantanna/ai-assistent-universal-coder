# Mantis Playbook

Orchestrates the AEOS-installed Mantis defensive security review suite.

Use this playbook for authorized security review campaigns that need repository history analysis, structural indexing, knowledge-base generation, threat modeling, planning, static research, finding deduplication, independent review, production viability checks, reproduction, exploit-chain analysis, patch planning, calibration, reflection and reporting.

Generated code execution and patch verification require explicit approval and isolated sandboxing.
