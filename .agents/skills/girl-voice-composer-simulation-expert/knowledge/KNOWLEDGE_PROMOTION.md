# KNOWLEDGE_PROMOTION — promotion rules

A candidate lesson is promoted to POSITIVE/NEGATIVE_KNOWLEDGE only when:

1. it is **generic** (not tied to a person or recording);
2. it is **reproducible** on the stated engine + parameters;
3. it has an **evidence pointer** (profile hash, engine, before/after note);
4. it contains **no personal data** or recording content.

Reject promotion otherwise. Never promote raw model output directly.
