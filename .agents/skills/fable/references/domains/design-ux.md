# Domain adapter: design and UX

Applies when deliverables involve user interface design, user journey mapping, wireframing, component spec, or accessibility audit.

## Minimum evidence set (binding)

1. **Brand design system / UI component guidelines**.
2. **User target persona & accessibility targets (WCAG 2.1 AA)**.
3. **Viewport/device targets**.

## Fraud table (for fable-judge)

| Fraud | Symptom |
|---|---|
| Unchecked accessibility | contrast ratios failing WCAG guidelines |
| Floating UI specs | designs lacking responsive layout math or token citations |
