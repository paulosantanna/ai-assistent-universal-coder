# AEOS Memory contract

Governance: CodENavi Full Workspace v2

Inherits root `AGENT.md`, `references/CODENAVI_FULL_WORKSPACE_STANDARD.md` and the current memory/promotion rules.

All memory operations follow **BRIEFING → RECON → PLAN → EXECUTE → VERIFY → DEBRIEF**.

Rules:
- raw execution output is not institutional knowledge;
- promotion requires validation, provenance and explicit confidence/uncertainty;
- stale or contradicted memory is corrected/deprecated, not silently retained as truth;
- secrets, credentials and raw sensitive material are never durable memory;
- prefer compact durable facts and pointers over copied implementation;
- negative knowledge records failed approaches and failure impact when useful;
- promotion/demotion must be traceable and reviewable.

Existing memory schemas inherit this standard automatically.
