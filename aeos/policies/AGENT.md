# AEOS Policies contract

Governance: CodENavi Full Workspace v2

Inherits root `AGENT.md` and `references/CODENAVI_FULL_WORKSPACE_STANDARD.md`.

Policy changes follow **BRIEFING → RECON → PLAN → EXECUTE → VERIFY → DEBRIEF**. Policies are deny-by-default for privileged behavior, have deterministic precedence, cannot silently weaken root governance, and must be validated against actual runtime enforcement. Policy text without enforcement must not be represented as a guaranteed control.
