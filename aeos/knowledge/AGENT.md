# AEOS Knowledge contract

Governance: CodENavi Full Workspace v2

Inherits root `AGENT.md` and `references/CODENAVI_FULL_WORKSPACE_STANDARD.md`.

Knowledge acquisition/promotion follows **BRIEFING → RECON → PLAN → EXECUTE → VERIFY → DEBRIEF**.

Requirements:
- source provenance and freshness are explicit;
- prefer authoritative/current sources for API/provider/framework claims;
- distinguish observation, inference and uncertainty;
- deduplicate conflicting knowledge and preserve conflict evidence;
- stale knowledge is updated/deprecated immediately when invalidated;
- no secrets or raw credentials are stored as knowledge;
- knowledge used for high-risk actions must be revalidated when freshness matters;
- summaries point to authoritative source/evidence instead of replacing it.

All existing knowledge registries and curated sources inherit this contract.
