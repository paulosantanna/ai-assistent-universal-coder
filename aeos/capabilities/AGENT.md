# AEOS Capabilities contract

Governance: CodENavi Full Workspace v2

Inherits root `AGENT.md` and `references/CODENAVI_FULL_WORKSPACE_STANDARD.md`.

Capability definitions follow **BRIEFING → RECON → PLAN → EXECUTE → VERIFY → DEBRIEF**. IDs are explicit, least-privilege and semantically stable. Skills/agents/playbooks may request only registered capabilities; new privileged capabilities require threat/risk analysis, policy mapping and runtime enforcement verification.
