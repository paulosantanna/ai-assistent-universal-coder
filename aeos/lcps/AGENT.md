# AEOS LCP contract

Governance: CodENavi Full Workspace v2

Inherits root `AGENT.md` and `references/CODENAVI_FULL_WORKSPACE_STANDARD.md`.

All LCP/context/language-intelligence contracts in this subtree follow **BRIEFING → RECON → PLAN → EXECUTE → VERIFY → DEBRIEF**.

Requirements:
- symbol/type/reference/dependency claims must be traceable to parser/index/server evidence;
- language and version support must be explicit;
- diagnostics must distinguish observed facts from inference;
- freshness-sensitive framework/runtime behavior is verified against current authoritative documentation;
- intelligence may guide changes but never bypass repository build/tests/evals;
- generated context is bounded and relevant; progressive disclosure is preferred;
- no secret persistence in indexes/context/evidence.

Legacy LCP contracts inherit this standard automatically.
