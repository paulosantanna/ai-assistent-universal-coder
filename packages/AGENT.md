# Workspace Packages contract

Governance: CodENavi Full Workspace v2

Inherits root `AGENT.md` and `references/CODENAVI_FULL_WORKSPACE_STANDARD.md`.

All packages follow **BRIEFING → RECON → PLAN → EXECUTE → VERIFY → DEBRIEF**. Package-local conventions remain authoritative when stricter. Dependency additions require demonstrated need, current compatibility evidence and lockfile consistency. Public contracts, build outputs and tests must remain verifiable; secrets never enter package source, fixtures or generated artifacts.
