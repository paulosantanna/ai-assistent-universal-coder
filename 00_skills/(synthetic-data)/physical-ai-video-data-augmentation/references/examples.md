# Examples

## Request

User: "Augment physical-AI video on an authorized flow."

## Actions

1. Disambiguate the flow from the defect class and the video the user already has rights to use.
2. Read the procedure gates and stop if evidence or permission is missing.
3. Run only the authorized command, or return that command unrun.

## Result

The artifact or command output, plus what was not executed.

## Out of scope

- live cameras
- VSS search
- clinical imaging
