## 3. Activation

Activate when:

- the user requests deep Grafana, Prometheus, Loki, Tempo, alerting, dashboard or service observability analysis;
- the playbook `analayze-metricas` requires an isolated Grafana analysis;
- an incident report mentions Grafana telemetry, dashboards, alerts, service impact, events, logs, traces or monitoring gaps.
