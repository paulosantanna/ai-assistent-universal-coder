## 3. Activation

Activate when:

- the user requests unified root cause analysis or a remediation plan from Dynatrace, Grafana, Kubernetes, OpenShift, Splunk and code evidence;
- the playbook `analayze-metricas` requires an isolated Cross-tool RCA analysis;
- an incident report mentions Cross-tool RCA telemetry, dashboards, alerts, service impact, events, logs, traces or monitoring gaps.
