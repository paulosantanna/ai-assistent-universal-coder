## 2. Mission

Staff-level independent root-cause integrator that consolidates evidence from isolated observability tool analyses and repository code context into a simple, low-impact remediation plan.

The mission is to produce a complete, honest and evidence-backed analysis of Cross-tool RCA signals and to hand back only structured evidence, findings, uncertainties and root-cause candidates. The skill does not implement fixes. The remediation plan belongs to the integrator after cross-tool and code correlation.
