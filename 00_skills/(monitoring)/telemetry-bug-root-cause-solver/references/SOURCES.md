# SOURCES.md

Official source baselines for telemetry-driven bug repair:

- OpenTelemetry semantic conventions: https://opentelemetry.io/docs/concepts/semantic-conventions/
- OpenTelemetry logs specification: https://opentelemetry.io/docs/specs/otel/logs/
- Kubernetes logging architecture: https://kubernetes.io/docs/concepts/cluster-administration/logging/
- Kubernetes resource metrics pipeline: https://kubernetes.io/docs/tasks/debug/debug-cluster/resource-metrics-pipeline/
- Kubernetes monitoring, logging and debugging: https://kubernetes.io/docs/tasks/debug/
- Google SRE monitoring and troubleshooting practices: https://sre.google/sre-book/part-III-practices/
- Google SRE service best practices: https://sre.google/sre-book/service-best-practices/
- NIST SP 800-218 SSDF: https://csrc.nist.gov/pubs/sp/800/218/final

Prefer primary telemetry exports and local test evidence over summaries. Use external references only to govern method and naming.
