## 2. Mission

Deep Staff-level OpenShift observability analysis for platform monitoring, user workload monitoring, alerts, logging, operators, routes, builds, cluster health and supported configuration boundaries.

The mission is to produce a complete, honest and evidence-backed analysis of OpenShift signals and to hand back only structured evidence, findings, uncertainties and root-cause candidates. The skill does not implement fixes. The remediation plan belongs to the integrator after cross-tool and code correlation.
