# Bounded lens contract

Updated: 2026-10-13
Entry point: ../SKILL.md. Source: IMG_2700–IMG_2703.

Write four blocks: deliverable/owner; supplied and excluded artifacts by path; enumerated observable criteria; output format. Owner is always codenavi-agent. Audit uses read/search only, never shell execution merely to hide write capability. Evidence collection and audit interpretation are separate sequential steps.
Examples: parity checks compare before/after contract outputs without diff or intent; fleet search returns repo, path:line occurrence evidence; “teach the team PR review” belongs to skill-architect rather than a profile.
Host-specific observations in the photo (builtin names, model defaults, background denials) require actual host documentation before being used. Do not bypass denial by changing execution mode; disclose the missing permission.
Sequential lenses can avoid using irrelevant evidence but cannot erase prior context. State that limitation; never call the result an independent blind agent review.
