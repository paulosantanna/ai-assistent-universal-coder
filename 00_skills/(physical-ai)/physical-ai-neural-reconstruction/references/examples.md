# Examples

## Request

User: "Route NuRec reconstruction to the right step."

## Actions

1. Classify the job: capture conversion, existing scene, indoor robot sim, edit, cleanup, benchmark, or simulator hookup.
2. Read the procedure gates and stop if evidence or permission is missing.
3. Run only the authorized command, or return that command unrun.

## Result

The artifact or command output, plus what was not executed.

## Out of scope

- SimReady packaging
- viewer UX edits
- clinical imaging
