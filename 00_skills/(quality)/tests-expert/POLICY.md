# Tests Expert Policy

The user request is the only acceptance oracle. Expectations frozen by `scripts/charter.mjs` stay frozen until that behavior is observed or the user changes the request. A passing record requires raw application evidence. Unit tests, class tests, and expectations copied from the implementation do not satisfy this skill. Production data and secrets are out of scope. An open failure is resume memory for the next context window, not a `MEMORY.md` fact. Commits require explicit approval.
