# Domain procedure

Inputs: Requested control framework, audit period/scope and authorized evidence references.

Outputs: Control-evidence matrix, redacted artifacts, integrity manifest and explicit exceptions.

1. Identify the requested controls and period; do not invent legal applicability.
2. Map each control to evidence with source, timestamp and scope.
3. Classify missing, stale or contradictory evidence as gaps rather than compliance.
4. Redact secret/private values and verify the exported manifest; report review limitations without certification claims.

Verification: apply the supplied domain contract to actual outputs; record source/version and executed check results. Missing required evidence, interface or permission blocks its dependent step. AGENTS.md governs; no independent agent identity or runtime installation is implied.
