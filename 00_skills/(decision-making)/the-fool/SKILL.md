# the-fool

Governance: CodENavi Full Workspace v2. Skill of `codenavi-agent`; inherit `AGENTS.md`.
Lifecycle: BRIEFING → RECON → PLAN → EXECUTE → VERIFY → DEBRIEF.

## Workflow

1. Obtain the decision, rationale, discarded alternatives and reversibility from supplied evidence. If rationale/alternatives are absent, return REPENSAR for missing basis; never invent an argument to defeat it.
2. Read [decision lens](lenses/the-fool.md). Steelman the actual choice; select only applicable internal modes from the retained references.
3. Run pre-mortem, surface load-bearing assumptions and falsifiers, red-team the strongest opposite case, and identify evidenced confirmation/sunk-cost/groupthink/anchoring/optimism/overconfidence biases.
4. Scale scrutiny to reversibility. Return SEGUIR / SEGUIR COM AJUSTE / REPENSAR with threats ordered by likelihood, assumptions, biases and evidence that would change the verdict.
5. Leave the final choice with its owner. Critique only; no code changes or new identities. Sequential self-critique cannot promise independent blind context.

Input: pending decision packet. Output: specific challenge report in PT-BR, without praise or invented findings. Source: IMG_2768–IMG_2770; retained TLC modes remain available under this contract.

## Examples and failure handling

Example: “challenge replacing this database” → rationale/alternatives/reversibility packet, premortem and specific verdict; a reversible style choice receives a short pass. Error: absent rationale → REPENSAR with missing basis, never an invented counterargument.
