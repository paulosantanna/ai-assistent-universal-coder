## Session Lifecycle
```
CREATE (import cookies) → VALIDATE (test request) → OPERATE (API calls) → CLOSE (cleanup)
     ↓                        ↓                        ↓
   30 days max           Auto-refresh           Auto-cleanup
   or cookie expiry      on use                 on expiry
```
