# Domain procedure

Inputs: Candidate packages/listings, target workspace constraints and trust/licensing policy.

Outputs: Evidence-based shortlist, metadata corrections, compatibility gaps and staging recommendations.

1. Inventory candidates and pin inspected source versions.
2. Check instruction scope, license/attribution, resources and actual required interfaces.
3. Detect duplicate capabilities, unsupported claims and incompatible activation boundaries.
4. Recommend eligible candidates and bounded corrections; leave installation/promotion to explicitly authorized workflows.

Verification: apply the supplied domain contract to actual outputs; record source/version and executed check results. Missing required evidence, interface or permission blocks its dependent step. AGENTS.md governs; no independent agent identity or runtime installation is implied.
