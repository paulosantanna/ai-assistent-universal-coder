Layout uses an 8-point grid with a 4px fine spacing step. Observed web/desktop body is 14–15px at line height 1.5; primary controls are 48px high with 16px padding; radii use 4/8/16px and a pill variant. Do not assume a pictured contrast label proves the resulting UI contrast: measure actual text/background pairs.

The photos reference Santander Headline and Santander Text local `.ttf` files. Use them only when authorized files are supplied; otherwise disclose the selected fallback. Do not fabricate an official font or flame SVG. Keep these reference values separate from another project's design system.
