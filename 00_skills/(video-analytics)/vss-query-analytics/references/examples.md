# Examples

## Request

User: "Query read-only VSS analytics."

## Actions

1. Confirm the analytics service is already configured and the user may read it.
2. Read the procedure gates and stop if evidence or permission is missing.
3. Run only the authorized command, or return that command unrun.

## Result

The artifact or command output, plus what was not executed.

## Out of scope

- video summarization
- archive embedding search
- sensor mutation
