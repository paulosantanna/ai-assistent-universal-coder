## 14. Decision matrix

Every major option must be scored using explicit criteria.

Recommended criteria:

- correctness;
- evidence strength;
- architecture fit;
- security;
- maintainability;
- performance;
- operability;
- reversibility;
- cost;
- implementation complexity;
- user impact;
- regulatory impact.

Scores summarize evidence; they do not replace it.

Weights must be visible.
