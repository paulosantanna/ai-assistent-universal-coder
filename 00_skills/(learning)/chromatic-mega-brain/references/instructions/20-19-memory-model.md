## 19. Memory model

```text
memory/
├── RUNS.md
├── COLOR_PERFORMANCE.md
├── DECISIONS.md
├── CONTRADICTIONS.md
├── LESSONS.md
└── FAILURES.md
```

Persist:

- run identifiers;
- selected colors;
- outcomes;
- evidence;
- judge verdict;
- useful and noisy colors;
- validated lessons.

Do not persist:

- secrets;
- unsupported conclusions;
- raw chain-of-thought;
- unreviewed speculation;
- personal data without need.
