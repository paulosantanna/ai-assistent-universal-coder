## 15. Evidence

Every material claim must cite:

- file and line;
- command and output;
- test;
- benchmark;
- runtime trace;
- authoritative documentation;
- standard;
- approved memory entry;
- explicit user constraint.

No evidence means `UNVERIFIED`.
