## 16. Handoff contract

Every color receives:

```yaml
chromatic_handoff:
  run_id:
  color:
  objective:
  problem_frame:
  scope:
  excluded_scope:
  evidence_available:
  assumptions:
  required_questions:
  expected_output:
  stop_conditions:
  memory_scope:
```

```yaml
color_handback:
  run_id:
  color:
  findings:
  evidence:
  assumptions_challenged:
  risks:
  opportunities:
  contradictions:
  recommendation:
  confidence:
  limitations:
```
