## 18. Judge gates

The Judge evaluates:

- problem framing;
- color selection;
- evidence quality;
- independence;
- contradiction handling;
- option completeness;
- decision criteria;
- security and governance;
- feasibility;
- unresolved risk;
- memory hygiene.

Valid verdicts:

- `PASS`
- `PASS_WITH_LIMITATIONS`
- `REWORK_REQUIRED`
- `BLOCKED`
- `WAITING_APPROVAL`
- `FAILED_VERIFICATION`
