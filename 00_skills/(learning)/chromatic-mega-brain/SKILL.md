# Chromatic Mega Brain

Governance: CodENavi Full Workspace v2. Skill of `codenavi-agent`; inherit `AGENTS.md`.
Lifecycle: BRIEFING → RECON → PLAN → EXECUTE → VERIFY → DEBRIEF.

## Mission

Organize the hierarchy of project intelligence so a new session resumes from verified state without copying common knowledge into every project. Hierarchy applies to data, never to agent identities.

## Workflow

1. Read workspace `.notebook/INDEX.md`, MEMORY and current HANDOFF/PROGRESS; load only relevant category/project notes. Read [ARQUITETURA](references/ARQUITETURA.md) when creating or changing the hierarchy.
2. Ensure the task's HANDOFF.md, MEMORY.md, PROGRESS.md and LEARNING.md exist. Reuse [continuity templates](templates/continuity/INDEX.md); create only missing files.
3. Keep current execution/checklists in PROGRESS and compressed transfer in HANDOFF. Record source pointers and exact next actions, never raw code/credentials.
4. Route durable facts/decisions through memory-curator and generalized lessons through learning-curator. Promote to the narrowest shared scope supported by evidence; leave a pointer rather than a duplicate.
5. Reconcile stale notes immediately. Verify quartet existence, evidence pointers and non-overlapping responsibilities before closing the phase.

## Inputs and outputs

Inputs: authorized project path, parent/category context, verified observations and current mission state.
Outputs: coherent indexed project intelligence, verified continuity quartet, promotion pointers and resumable next actions.

## Boundaries and verification

Do not create empty knowledge hierarchies or invent facts. Never persist secrets, cookies, personal data or private reasoning. Missing evidence blocks promotion. The root `.notebook/` protocol takes precedence over photographed root-level memory examples.

The previous reasoning/color workflow is retained as [bounded cognitive references](references/instructions/INDEX.md). Use it only when that analytical scope is requested; all roles are lenses of the same canonical agent, and no self-review may be called independent.
