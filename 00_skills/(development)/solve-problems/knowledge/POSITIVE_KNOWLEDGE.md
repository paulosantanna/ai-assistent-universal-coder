# POSITIVE_KNOWLEDGE.md

Validated repair patterns for this skill:

- Reproduce the failure before changing code when technically possible.
- Detect language from repository evidence, not only from the user's words.
- Prefer the smallest change that matches existing local style.
- Use repository-native tests, linters, type checkers and build commands.
- Inspect diff before completion for comments, unused imports, orphan variables and architecture drift.
- Record Memory, Handoff, progress, Learning, evidencias and analise artifacts for material repairs.
