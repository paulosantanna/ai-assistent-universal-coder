# Framing and Copy Generation

## One Frame Per Video

- Each video gets exactly one frame (thumbnail/image)
- Generated from the creative assembly stages
- One description + maximum 5 tags per network

## Per-Network Format

### TikTok

- Max 5 tags (hashtags)
- Description optimized for mobile-first viewing
- Vertical video format (9:16)

### Instagram Reels

- Max 5 tags (hashtags)
- Description with emoji support
- Vertical video format (9:16, up to 15s or 30s)

### YouTube Shorts

- Max 5 tags (hashtags)
- Description with timestamps optional
- Vertical video format (9:16, up to 60s)

## Copy Generation Rules

- One description per video (no multiple captions)
- Max 5 tags total across all networks per video
- No duplicate caption/frame paths
- Descriptions auto-generated from video metadata + LAYA context
- Tags selected from trending + content policy approved list

## Frame Generation

- Generated from creative `assembly.py` stages
- One frame per video only
- Resolution optimized per platform
- No second frame or caption path added
