Updated: 2026-10-27. Owner: codenavi-agent. Lifecycle: BRIEFING → RECON → PLAN → EXECUTE → VERIFY → DEBRIEF.

## Objective and scope
Create original TLC-format Staff expert skills and an executable local playbook for PT-BR scientific motion comics, from a topic to a reviewed MP4. Default profiles: short 60 s vertical, youtube 600 s landscape, documentary 3600 s and full-documentary 5400 s landscape. Male documentary narration, detailed cartoon/comic art, independent layers/camera, parallax, controlled scientific effects, discreet subtitles, contextual transitions, no speech balloons. Local CLI and Dark-videos entry point consume the same project contract. Publishing always remains a separate reviewed action.

## Approach and acceptance
- Canonical skills <=100 physical entry lines, progressive modules, explicit Staff domain decisions, examples/errors, source attribution, native discovery and catalog validation.
- Shared JSON project with scene narration, evidence IDs, local assets, keyframes, bounded effects and timing; deterministic Python/FFmpeg rendering; optional generated video clips.
- Provider commands are operator configuration, argv only, no shell. No dependency installation or paid provider selection without disclosure. A local planning model may draft, never certify science.
- Render scenes incrementally, cache by content + assets + configuration; support retries without repeating unchanged scenes. Long profiles are chaptered; duration is validated, never achieved by silently looping filler.
- CLI can initialize all profiles, inspect prerequisites, render supplied assets, create review evidence and gate export by content hashes. Automated topic-to-assets requires configured local providers; missing engines fail explicitly.
- Dark-videos integration is staged, verified in isolation then installed with filesystem permission. No auto-release into its publisher.
- Verify real short render, independent layer motion, audio/video streams/duration, stale-review refusal and provider failures. Explicitly distinguish fixture validation from a generated documentary or evaluated narrator.

## Risk and verification
Primary risks: unsupported scientific claims, artistic distortion mistaken for physical simulation, unavailable model weights, long rendering cost/disk, speech timing drift, automatic publication bypass. Use claim ledger, illustration labels, capability preflight, chaptered asset cache, actual audio duration and reviewed export. No new agent identity. No remote publication in this mission.
