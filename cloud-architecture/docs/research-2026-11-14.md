# Pesquisa de arquitetura cloud AWS e Azure: melhores práticas, custo e desempenho

Data: 2026-11-14. Escopo: práticas atuais e formas de arquitetura na AWS e no Azure, com foco em desempenho e custo. Fontes oficiais primeiro; cada afirmação numérica tem origem registrada em `cloud-architecture-mcp/evidence/claims.json` ou em `cloud-architecture-mcp/providers/*/prices.json`.

## 1. Método e limites

- **AWS**: documentação oficial pela ferramenta `aws___search_documentation` (trechos verbatim das páginas). Preços pela Price List pública em JSON (sem credenciais), com SHA-256 de cada arquivo.
- **Azure**: páginas oficiais do Microsoft Learn lidas por extrato (WebFetch), páginas oficiais para Artifact Signing e o repositório do Azure MCP. Preços pela Azure Retail Prices API (sem autenticação).
- **JEV (TypeSafe, Noul)**: triagem de 65 claims contra o trecho de origem. Controles negativos e de ausência foram incluídos para medir a separação. JEV é triagem, não prova. Resultado: 48/50 positivos e 15/15 negativos na rodada final; a rodada 1 (43/50) foi mantida como evidência. Dois casos limítrofes foram verificados à mão.
- **Limites**: preços são de lista, sem Savings Plans, reservas, descontos de volume e impostos. Itens sem fonte no snapshot estão marcados como não verificados. Nada foi implantado.

## 2. Princípios que valem nos dois provedores

1. **Medir antes de cortar.** Custo sem medição de carga é palpite. O cenário-alvo de cada projeto traz premissas explícitas.
2. **Escala a zero só quando a latência tolera.** Inferência com p95 de 15 s não tolera cold start de minutos (AWS async). Nos dois provedores, escala a zero por CPU ou memória não chega a zero no Container Apps.
3. **Resiliência não se corta para economizar.** Três dedicated masters no OpenSearch e HA com redundância de zona são recomendações, não luxo.
4. **Rede privada por padrão.** Em AWS, cada endpoint de interface cobra por hora em cada zona. Em Azure, o PostgreSQL com VNet nega acesso público.
5. **Credenciais de vida curta.** GitHub Actions com OIDC nos dois provedores (AWS: `sub` obrigatório na trust policy).
6. **Região tem preço.** Nos snapshots, São Paulo custa 1,6 a 2,1 vezes mais que a Virgínia na AWS; Brazil South custa 2,0 vezes mais que East US na GPU A10 da Azure. Residência de dados contra custo é decisão de ADR.
7. **Trilha de auditoria imutável.** AWS: S3 Object Lock em modo compliance (governance pode ser contornada). Azure: política WORM por tempo bloqueada; política por versão exige versionamento.

## 3. AWS: padrões por tipo de carga

| Carga | Padrão recomendado | Número ou fato verificado | Armadilha |
| --- | --- | --- | --- |
| API HTTP/SSE sem GPU | **ECS Express Mode** (Fargate, ALB, HTTPS, auto scaling) | Sem custo extra além dos recursos; sub-redes privadas geram ALB interno | **App Runner está fechado a novos clientes**; migrar para ECS Express |
| Computação | Fargate **ARM64** (Graviton) | Preço sa-east-1: vCPU US$ 0,0557/h contra US$ 0,0696 x86 (-20%); GB US$ 0,00612 contra US$ 0,0076 | Números de "40% melhor desempenho" são de Graviton2 em 2021; medir a geração atual |
| Economia de computação | Compute Savings Plans | Cobre EC2, Fargate e Lambda; até 66% (oficial) | Não cobre Aurora, OpenSearch nem SageMaker (não verificado para reservas RDS/ES) |
| Relacional | Aurora PostgreSQL: produção Multi-AZ; homologação em Serverless v2 | Serverless v2 com 0 ACU pausa após 300 s a 86.400 s; mínimo ≥ 0,5 ACU desativa a pausa | Retomada após pausa não medida; ACU sa-east-1 US$ 0,25/h |
| Busca híbrida (BM25 + vetor) | OpenSearch gerenciado Multi-AZ | **3 dedicated masters** recomendados em produção | Dois masters ou número par não têm quórum |
| Vetores em lote | S3 Vectors | GA em dezembro de 2025; até 2 bilhões de vetores por índice; redução de consulta até 80% acima de 10 milhões (vendor) | Latência de cerca de 100 ms; não usar para busca interativa rápida |
| OpenSearch Serverless | Mínimo 0 OCU por grupo | No GA, a primeira coleção provisionava 4 OCU (histórico) | Verificar o mínimo atual antes de assumir custo zero |
| Rede | Gateway endpoint S3 (grátis) + interface endpoints só onde a carga exige | Interface: US$ 0,021/h por endpoint por AZ em sa-east-1 (US$ 0,01 em us-east-1) + US$ 0,01/GB | 9 endpoints x 2 AZ = cerca de US$ 276/mês só em hora |
| NAT Gateway | Evitar quando endpoints bastam | Cobra por hora e por GB processado | Preço em sa-east-1 não está no snapshot: medir |
| Distribuição estática | S3 privado + CloudFront (OAC) | **PriceClass_100 e PriceClass_200 não incluem a América do Sul**; só PriceClass_All inclui | Free tier permanente: 1 TB e 10 milhões de requisições por mês |
| CI/CD | GitHub OIDC para AWS | Credenciais temporárias; IAM rejeita trust policy sem `sub` | Chave estática de IAM no segredo do CI |
| Observabilidade | Agente CloudWatch com OTLP (métricas e logs com bearer) | Padrão do agente: 127.0.0.1:4318 | **Traces para o X-Ray não aceitam bearer** (usar SigV4 via ADOT) |
| Logs | Retenção definida; ingestão padrão | US$ 0,90/GB em sa-east-1 (US$ 0,50 em us-east-1) | Logs são a conta que cresce sem aviso |
| Inferência de modelo local | SageMaker **async com scale-to-zero** (carga intermitente e latência tolerante) | Escala a zero no async; cold start de minutos | Endpoint real-time sempre ligado: ml.g5.xlarge US$ 2,394/h em sa-east-1 |
| Treino | Managed Spot com checkpoint, ou Flexible Training Plans para janela fixa | Até 90% de economia sobre sob demanda (teto); planos de até 65% (oficial) | Spot sem checkpoint perde trabalho |
| Trilha de auditoria | S3 Object Lock | **Governance** pode ser removida por quem tem `s3:BypassGovernanceRetention`; **compliance** nem o root remove | Compliance é irreversível no período: exige ADR |
| Governança | Well-Architected com **seis** pilares (inclui Sustentabilidade) | Oficial | Confundir com os cinco pilares do Azure |

## 6. Formas de arquitetura recomendadas, por caso

- **Aplicativo desktop sem backend (MyDigitalBuddy)**: sem runtime de nuvem. S3 privado + CloudFront + OIDC. Custo medido de S3 de cerca de US$ 0,05/mês. Assinatura Windows fora da nuvem.
- **API governada com dados sensíveis (AIHealthResearch)**: rede privada, ALB interno, banco Multi-AZ com proteção contra exclusão, KMS, Object Lock compliance, inferência agendada (sem escala a zero por causa do p95 de 15 s), treino Spot com checkpoint. Modelo e detalhes em `cloud-architecture/docs/aws-aihealthresearch.md` e `azure-aihealthresearch.md`.
- **API interna de baixa carga**: ECS Express (AWS) ou Container Apps com ingresso interno (Azure); homologação com banco pausado (Aurora 0 ACU ou Azure parado).
- **Telemetria OpenTelemetry**: AWS com agente CloudWatch (métricas e logs) e ADOT com SigV4 (traces); Azure com a distribuição oficial para Java.

## 7. Incertezas e lacunas (não verificadas nesta rodada)

- NAT Gateway em sa-east-1; KMS (chave e requisições); CloudFront transferência; Cognito; Lambda; EventBridge; SQS; ECR; retenção de logs do CloudWatch.
- Azure: AI Search (preço por SKU), Private Endpoint, Key Vault, Front Door, cobrança do standby de HA, escala a zero de endpoint batch do Azure ML.
- Graviton: a documentação consultada cita Graviton4 como geração mais recente; Graviton5 não apareceu nas buscas oficiais. Confirmar antes de decisão.
- Preço de Spot e de reservas não está no snapshot (Price List com OnDemand); os fatores de Spot usados são premissas.
- JEV: triagem de 65 claims, não avaliação de modelo; os controles foram escritos pelo mesmo agente.
